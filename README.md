# 仪轨偈颂 藏文学习

以常念的仪轨偈颂为核心的藏文学习 PWA：从零基础拼读开始，然后一句一句学偈颂，每句把词拆开学，再背下来。读音为安多音。学法照「科判颂词背诵器」（kepan-app），颂词来自「藏汉课诵阅读器」（daily_recitation_reader）的颂词库。

## 内容来源

- 仪轨偈颂：藏文、汉译、课诵本音译来自喇荣课诵（2024-05-02 版），逐词释义（按格律分组，每组一个汉义）是课诵阅读器里起草的，还在校对。由 `scripts/build_verses.py` 从课诵阅读器仓库生成 `public/verse/verses.json`。
- 读音：
  - 字母、元音组合（L-、CV-）和能对上的音节卡、词卡（`public/audio/real/`）用的是《安多方言会话教材》Flash 课件里的真人录音，由 `scripts/build_real_audio.py` 生成，每段的出处见 `scripts/data/amdo-real.tsv`，藏文 → 音频编号见 `src/real-audio.json`。
  - 偈颂词的读音（`public/verse/w/`，约 45 MB）是课诵阅读器的共用词库：Meta MMS 安多藏语 TTS（`facebook/mms-tts-adx`，CC BY-NC 4.0）合成、w 按词挑过的候选。教材里没有录音的音节、词也用这个模型生成，尚未经人工校对。
- 原来的《普贤上师言教》全书原文、高频词和精读已经去掉（2026-11-18 改成偈颂）。开篇的数据还留在 `src/opening.json` 等文件里，拼读课程的音节和例子要用。

## 课程结构

学习只有一条线，分两个阶段（首页“学习进度”能看到在哪一段）：

1. **拼读**：30 个字母、4 个元音、字母元音组合、加字规则和没有加字的简单词（原来 1–9 单元的内容，按原顺序，`SPELL_SEQ`）。
2. **仪轨偈颂**（`src/verses.ts`）：30 个字母都学过以后开始，和拼读收尾并行。学习线 1580 句：先学短而常念的（皈依偈、四无量心、皈依发心、回向偈、七句祈祷文……普贤七支供），再按句数从少到多学其余的祈祷文、发愿文，最后是长篇（八吉祥颂、菩萨戒、释迦佛修法、上师相应法、前行、无诠义忏、文殊大圆满愿文、普贤行愿品、极乐愿文）。咒语、名号没有逐词释义，只在仪轨页里读。同一句在几部仪轨里都有的只学一次。知识点：`G:词`（全 App 一张卡，3451 个）、`J:仪轨/句`。

- **今天**（`src/Today.tsx`、`src/practice.ts`、`src/Practice.tsx`）：首页一个按钮，大约 15 分钟，按顺序三段，每段做完的小结页底部写明下一段，可以继续，也可以先停：
  1. **卡片**：到期复习和新卡混在一个队列里（字母、组合、规则、词，加上学过的偈颂词的复习），复习最多 60 张，新卡按复习多少在 4–14 张之间浮动（刚开始一周最多 8 张）。新卡 4 张一组：先看介绍（新字母后面接两遍描字），马上每张一道选择题，最后每张再换个问法考一次。复习大多是**回忆卡**：先自己想（意思或读音），点“想好了，翻面”，再自评“不会 / 模糊 / 会”；偈颂词和词有四分之一是只放声音的听音回忆；字母每隔几次凭记忆默写一次（一天最多 4 张），写完把标准字叠上去对照。**卡片做完就算签到。**
  2. **安多会话**：按教材顺序每天 3 句新的（听真人录音 → 跟读，录下来和原音前后连着听），到期的会话句听音回忆，最后新句各考一道选择题。
  3. **偈颂**：字母没学完时读一句偈颂，只看不考。之后照「科判颂词背诵器」的学法，每天新学 1–3 句（新词凑够约 10 个就停）：这句里没学过的词一个个介绍（藏文、安多拼音、这句里的释义、发音、这句做例句）→ 每个词一道选意思 → 整句（逐词排，下面注音和释义，再下面汉义，“逐词听”一个词接一个词放、正在放的词高亮）→ 对照（看藏文选汉义、看汉义选藏文，干扰项先用同一部仪轨的句子）→ 遮字背诵：通读 → 遮三分之二 → 只留首字，看着汉义背，点空白可以偷看一个音节，背完看原文自评“不会 / 模糊 / 记得”。到期的旧句放在新句前面，只留首字背一遍（一天最多 12 句）。偈颂词的复习在卡片那段。
- 不再有关卡、单元小测和定时抽查：FSRS 排的到期复习就是持续的抽查。“复习”入口只做现在到期的卡。
- **界面最多三层**：第一层是底部三个页签——今天、仪轨、资料；第二层是从页签点进去、顶上带返回的一页（详细进度、设置、资料里的一项、一部仪轨）；第三层是在第二层里打开的东西（一课课文、一次练习、流利度测验）。
- **学习进度**（首页下半，`src/overview.ts`）：一条全程的条子分两段（拼读 → 仪轨偈颂），每个阶段一行“学了多少 / 一共多少”，偈颂下面再写学过多少个词，正在学的加粗，没开始的灰色，加上并行的安多会话（多少 / 305 句）。首页不放说明文字，说明都在“详细进度”里。今天的三段只写名称和分钟数；签到日历点“连续 N 天”展开。
- **详细进度**（第二层，`src/Progress.tsx`）：偈颂学了多少句、多少词，每部仪轨学了几句（点一部去仪轨页看）；拼读学到哪了；**拼读流利度测验**（从偈颂里最常见的 200 个词里抽 20 个，每个 3 秒内念出来，再听发音自己对照，对 90% 算过关）。
- **设置**（首页右上角齿轮）：多复习一次（现在到期的卡）、**记忆强度**三档（轻松 85% / 标准 90% / 牢固 95%，就是 FSRS 的目标记住率，`src/prefs.ts`）、Wylie、声音测试、导出/恢复、重置、标记过的问题。
- 第一次打开先看一屏欢迎页。
- **仪轨页**（`src/Rituals.tsx`）：按课诵阅读器的分类（修法仪轨、祈祷文、咒语名号、发愿回向、皈依发心、供养忏悔）列出 138 部仪轨，每部写明学过几句。点进一部：逐句排，每句逐词（藏文、注音、这句里的释义，`src/VerseLine.tsx`），下面汉义；句前 ▶ 逐词听，句后圆点表示学过没有；点词看释义（和常见意思不同时也写上）、听发音。注音、释义、汉义的开关收在“Aa”里（`src/readerPrefs.ts`）。

- 每日小游戏暂时收起来了（`src/Games.tsx` 代码还在，没有入口）。

- **安多会话教材**（《安多方言会话教材》，真人录音）：会话 300 句按教材顺序在“今天”的会话段里学；口语词（`D:编号`）和拼读表（`P:编号`）按“用到的字母、元音、加字都学过了”的顺序跟着拼读走。知识点 `A:编号`（会话）、`D:`、`P:` 都进遗忘曲线复习。
- **资料页**：一张清单（字母表、会话 300 句、单词、拼读表、课文、注音怎么读），每项点进去一页，有字母表和教材全部内容，用来单独翻看和强化：会话 300 句、单词、拼读表、第 11–36 课课文（课本页面切成段，点哪段播哪段）。数据由 `scripts/build_amdo.py` 生成 `src/amdo.json`（含每个词的音节结构分析），录音和课文图片在 `public/amdo/`（约 47 MB，不预先缓存，用到才下载）。
- **拼读的顺序**按安多话排：先学 30 个字母（按字母表顺序）、4 个元音和没有加字的简单词（口语词，真人录音）；一个字母和 4 个元音都有点熟了（答过两次以上、最近没答错）才开始学这个字母的组合；然后学加字，一次一类：后加字和再后加字（韵尾）→ 前加字和上加字（声母前多一个短音）→ 下加字（声母本身变了）。安多话不分声调，加字大多要读出来，以录音为准。
- **偈颂数据**：`python3 scripts/build_verses.py <daily_recitation_reader 仓库目录>` 重新生成 `public/verse/`。颂词库改了（加仪轨、改释义、换发音）就重跑一次。发音按课诵阅读器发布页 `index.html` 里的 LEX 表（词 → `a/<哈希>.mp3`）取。`verses.json` 打开时才下载，发音用到才下载，下载过的存起来离线可用。
- **回忆题**（`recallQuestion`、`recallFor`，`src/course.ts`）：复习时大多是自评的回忆卡（见上）；音节和拼读表格子三分之一换成拼字（听真人录音，给前加字、基字、元音……每个位置选字）。还有听写词、找错（音节拆解里有一处把别的字标成了基字，点出来）。听会话句选意思时选项晚 3 秒出（先想再看）。跟读后自评“读得像 / 还差一点”。前加字、上加字、基字等在全 App 用固定颜色。
- **答题反馈**：第一次答错不直接给答案，而是按选了哪个错项给一句提示（形近字、音近字、元音、基字、词义、会话句，见 `src/hints.ts`），划掉这个选项再选一次；第二次还错才揭晓。作答记录里存了题型、用时、选错的选项和误区类别。
- **注音**全 App 用**安多拼音**（`src/amdoPron.ts`）：按安多话的实际读音、用汉语拼音字母写，不用 Wylie。声母和拼音同音（b d g 不送气、p t k 送气），前加字、上加字读成的轻音用小上标 ʰ ⁿ（རྒྱ་མཚོ ʰjia ⁿco），e 是“的”的韵母、ê 是“欸”，后加字 ག བ ད 读 -k -p -l，ལ ས 不读只改元音。规律依据宋国明《Colloquial Amdo Tibetan》、Green 2012 和安多韵母史研究，用孙宏开词表里夏河、泽库两点的读音核对（`npm run check:pron`，数据 `scripts/data/sun-amdo.tsv`，来自 lexibank/suntb，CC BY 4.0）。字母、元音组合、开篇、偈颂、会话都用同一套；字母的汉字近音仍照《一本通》。资料里有“注音怎么读”。`ོ` 开音节写 o（两地数据都读 o，《一本通》有几个写 u），待听阿坝录音确认。
- **Wylie 转写**默认不显示，也不出转写题；设置里可以打开（`src/prefs.ts`）。注音相同的清浊字，浊音那个的汉字后加“·浊”（如 ག ga 嘎·浊）。前加字、上加字、后加字的讲解按安多话：大多要读出来，以录音为准。
- **掌握判定**：一个知识点最近 7 次至少对 6 次，并且隔天还答对过。
- **FSRS 评分**：选择题一次答对按用时分档（慢一倍以上 Hard，其余 Good；选择题最多记 Good，因为认出来比想出来容易），提示后才答对记 Hard，答错 Again；答对后可以点“其实是猜的”改记 Hard。回忆卡按自评记：不会 Again、模糊 Hard、会 Good，“不会”的卡当天过几张再出一次。
- **定时回顾**：所有内容共用一份 FSRS 记录（`db.cards`），同一个字母只记一份熟练度。旧版字卡的“盒子”记录在启动时由 `src/migrate.ts` 搬进 FSRS；旧版闯关学过的内容照样留在复习里。

开篇逐词数据（分词、一本通式注音、音频编号）由 `scripts/build_opening_words.py` 从 `scripts/data/opening-words.tsv` 生成 `src/opening-words.json`；音频在 `public/audio/op/`。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建到 dist/
python3 scripts/build_verses.py ../daily_recitation_reader  # 从课诵阅读器的颂词库重新生成偈颂数据
npm run check:questions  # 题库检查：把 1–10 单元和会话的每种题都生成一遍，查答案不在选项里、选项重复、听不出来的干扰项等
npm run check:pron       # 拿夏河、泽库词表检验注音规律（--list 列出对不上的）
```

推送到 `main` 后，GitHub Actions 会自动部署到 GitHub Pages。
