# 普贤上师言教 藏文学习

以《大圆满前行·普贤上师言教》藏文原文为核心的藏文学习 PWA：从零基础拼读开始，逐步过渡到原文诵读和理解。读音为安多音。

## 内容来源

- 藏文原文：华智仁波切《普贤上师言教》。
- 读音：
  - 字母、元音组合（L-、CV-）和能对上的音节卡、词卡（`public/audio/real/`）用的是《安多方言会话教材》Flash 课件里的真人录音，由 `scripts/build_real_audio.py` 生成，每段的出处见 `scripts/data/amdo-real.tsv`，藏文 → 音频编号见 `src/real-audio.json`。
  - 文章部分（开篇整句、开篇逐词、全书原文）和教材里没有录音的音节、词，仍是 Meta MMS 安多藏语 TTS（`facebook/mms-tts-adx`，CC BY-NC 4.0）自动生成，尚未经人工校对。
- 中文译文有版权，**不在本仓库中**。需要时在 App 的“我的”页里导入本地的译文包。

## 课程结构

学习只有一条线，分三个阶段（“进度”页能看到在哪一段）：

1. **拼读**：30 个字母、4 个元音、字母元音组合、加字规则和没有加字的简单词（原来 1–9 单元的内容，按原顺序，`SPELL_SEQ`）。
2. **原文高频词**：30 个字母都学过以后开始，和拼读收尾并行。按全书词频从高到低学（知识点 `F:词`），前 100 个词约占全书词次 43%，前 300 个约 58%，前 1000 个约 76%，前 1500 个约 82%。每个词配一句原文例句（尽量挑“只有这个词还没学”的短句），读音从例句整句音频里切出来。
3. **有声精读**：学到 300 个高频词以后，每天读一段原文。

- **今天**（`src/Today.tsx`、`src/practice.ts`、`src/Practice.tsx`）：首页一个按钮，大约 15 分钟，按顺序三段，每段做完的小结页底部写明下一段，可以继续，也可以先停：
  1. **卡片**：到期复习和新卡混在一个队列里（字母、组合、规则、词、高频词交替出），复习最多 60 张，新卡按复习多少在 4–14 张之间浮动（刚开始一周最多 8 张）。新卡 4 张一组：先看介绍（新字母后面接两遍描字），马上每张一道选择题，最后每张再换个问法考一次。复习大多是**回忆卡**：先自己想（意思或读音），点“想好了，翻面”，再自评“不会 / 模糊 / 会”；高频词和词有四分之一是只放声音的听音回忆；字母每隔几次凭记忆默写一次（一天最多 4 张），写完把标准字叠上去对照。**卡片做完就算签到。**
  2. **安多会话**：按教材顺序每天 3 句新的（听真人录音 → 跟读，录下来和原音前后连着听），到期的会话句听音回忆，最后新句各考一道选择题。
  3. **原文**：高频词不到 300 个时，听开篇的一句，只听、跟读；之后是“今天的一段”（`src/TodayReading.tsx`）：段落按全书顺序往下走（每段不超过 8 句，可以换成接下来 40 段里认识的词最多的一段），固定五步：听整段（逐词高亮）→ 不放声音自己读，不认识的词点一下（常见的词读完加进卡片）→ 跟读 → 看中文（导入了译文才有）→ 一道词义题。
- 不再有关卡、单元小测和定时抽查：FSRS 排的到期复习就是持续的抽查。“复习”入口只做现在到期的卡。
- **进度页**（`src/Progress.tsx`）：现在在哪个阶段；原文里认识的词占全书多少，每章各占多少（点一章去读）；拼读学到哪了；**拼读流利度测验**（从原文最常见的 200 个音节里抽 20 个，每个 3 秒内念出来，再听录音自己对照，对 90% 算过关）；**记忆强度**三档（轻松 85% / 标准 90% / 牢固 95%，就是 FSRS 的目标记住率，`src/prefs.ts`）。
- 第一次打开先看一屏欢迎页。底部 5 个页签：今天、进度、原文、资料库（字母表 + 安多会话教材）、我的（复习记录 + 设置）。
- 原文页和今天的一段在放音频时，正在读的词会高亮（`src/karaoke.ts`，按整句音频里的音节时间）。
- 原文页顶上一个标题，点开是目录（开篇各段 + 14 章）；注音、释义、中文、逐句对照的开关收在“Aa”里（`src/readerPrefs.ts`），开篇和各章共用。正文居中排，有声音在放时底部出播放条。
- 每日小游戏暂时收起来了（`src/Games.tsx` 代码还在，没有入口）。

- **安多会话教材**（《安多方言会话教材》，真人录音）：会话 300 句按教材顺序在“今天”的会话段里学；口语词（`D:编号`）和拼读表（`P:编号`）按“用到的字母、元音、加字都学过了”的顺序跟着拼读走。知识点 `A:编号`（会话）、`D:`、`P:` 都进遗忘曲线复习。
- **资料库页**：字母表，和教材全部内容，用来单独翻看和强化：会话 300 句、单词、拼读表、第 11–36 课课文（课本页面切成段，点哪段播哪段）。数据由 `scripts/build_amdo.py` 生成 `src/amdo.json`（含每个词的音节结构分析），录音和课文图片在 `public/amdo/`（约 47 MB，不预先缓存，用到才下载）。
- **拼读的顺序**按安多话排：先学 30 个字母（按字母表顺序）、4 个元音和没有加字的简单词（口语词，真人录音）；一个字母和 4 个元音都有点熟了（答过两次以上、最近没答错）才开始学这个字母的组合；然后学加字，一次一类：后加字和再后加字（韵尾）→ 前加字和上加字（声母前多一个短音）→ 下加字（声母本身变了）。安多话不分声调，加字大多要读出来，以录音为准。
- **原文高频词表**由 `scripts/build_vocab.py` 生成 `public/book/vocab.json`（1500 个词，每个词的次数、例句和例句里的时间；最常见的 200 个音节和一段录音；每章里各个词出现几次），用到时才下载，释义取自全书词表。
- **回忆题**（`recallQuestion`、`recallFor`，`src/course.ts`）：复习时大多是自评的回忆卡（见上）；音节和拼读表格子三分之一换成拼字（听真人录音，给前加字、基字、元音……每个位置选字）。还有听写词、找错（音节拆解里有一处把别的字标成了基字，点出来）。听会话句选意思时选项晚 3 秒出（先想再看）。跟读后自评“读得像 / 还差一点”。前加字、上加字、基字等在全 App 用固定颜色。
- **答题反馈**：第一次答错不直接给答案，而是按选了哪个错项给一句提示（形近字、音近字、元音、基字、词义、会话句，见 `src/hints.ts`），划掉这个选项再选一次；第二次还错才揭晓。作答记录里存了题型、用时、选错的选项和误区类别。
- **注音**全 App 用安多话的类拼音（一本通写法）：字母和组合照书，开篇照人工写的，其余任何音节由 `src/amdoPron.ts` 按规律推（拆出前加字、上加字、基字、下加字、元音、后加字，声母换成读音相同的字母查表，再按“元音 + 后加字”配韵母；全书音节覆盖约 99.9%），原文、高频词、会话 300 句、口语词、拼读表都显示。资料库和“我的”里有“注音怎么读”，只讲和普通话拼音不同的几处（结尾 f/r、·浊、不写出来的前加字）。规律没有逐个核对，以录音为准。
- **Wylie 转写**默认不显示，也不出转写题；“我的”页里可以打开（`src/prefs.ts`）。注音相同的清浊字，浊音那个的汉字后加“·浊”（如 ག ga 嘎·浊）。前加字、上加字、后加字的讲解按安多话：大多要读出来，以录音为准。
- **掌握判定**：一个知识点最近 7 次至少对 6 次，并且隔天还答对过。
- **FSRS 评分**：选择题一次答对按用时分档（慢一倍以上 Hard，其余 Good；选择题最多记 Good，因为认出来比想出来容易），提示后才答对记 Hard，答错 Again；答对后可以点“其实是猜的”改记 Hard。回忆卡按自评记：不会 Again、模糊 Hard、会 Good，“不会”的卡当天过几张再出一次。
- **定时回顾**：所有内容共用一份 FSRS 记录（`db.cards`），同一个字母只记一份熟练度。旧版字卡的“盒子”记录在启动时由 `src/migrate.ts` 搬进 FSRS；旧版闯关学过的内容照样留在复习里。

全书原文（开篇以外的 14 章，10,109 句）在“原文”页按章阅读：`scripts/build_book.py` 把句子表、botok 分词和整句音频的音节时间切成 `public/book/chNN.json`，整句音频转成 24 kbps 单声道 AAC 放在 `public/book/audio/`（约 170 MB）。这部分不预先缓存，打开哪一章才下载哪一章，听过的句子会存下来；每章也可以点“离线听本章”一次存完。点词时播的是整句音频里那个词的一段。全书中文译文同样不在仓库里，用“设置”导入全书译文包（含 `book` 字段，按段落编号 p0009… 存）。

**逐词释义和藏汉逐句对照**（`src/gloss.ts`、`src/align.ts`）：原文每个词下面有一行小字释义（“释义”按钮开关），点词看完整释义。词表 `scripts/data/book/gloss.tsv`（约 4400 条，按全书分词后的词形逐条写，高频词在前；释义前带 `?` 的是推测、还没核对，App 里标“推测”）由 `scripts/build_gloss.py` 生成 `public/book/gloss.json`，打开原文时才下载。查词顺序：课程词表里的人工释义 → 全书词表 → 去掉粘在词尾的助词（འི ས ར འང འམ འོ）再查，同时说明助词的作用 → 按音节拆成词表里有的几段分别给意思。整词能直接查到的约占全书词次 95.6%，拆开查到的约 4%。导入了全书译文后，“逐句对照”把每段译文按 ，。；：！？ 切成分句，再用动态规划按长度（汉字约为藏文音节的 1.3 倍）和词义（藏文词的释义在中文里出现）对到藏文句子上，几句藏文对一组中文，显示在这几句下面；点词时，这组中文里对应释义的字会标出来。译文语序和藏文不同，可能对偏一两句。`npm run check:align -- <全书译文包.json> [段落编号…]` 打印对照样例和命中率（译文包不在仓库里）。

每章读完最后有“做本章练习”（`src/bookQuiz.ts`，约 10 题）：本章出现的、词表或安多教材里有的词看词选意思；给一句原文选出句里的那个词；导入了译文的话，再给一段原文选中文意思。词题用原来的 `W:`/`D:` 知识点进复习，段落题记为 `B:段落编号`，只记作答，不进复习。

开篇逐词数据（分词、一本通式注音、音频编号）由 `scripts/build_opening_words.py` 从 `scripts/data/opening-words.tsv` 生成 `src/opening-words.json`；音频在 `public/audio/op/`。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建到 dist/
npm run check:align -- <全书译文包.json>  # 看逐句对照和逐词释义的效果
npm run check:questions  # 题库检查：把 1–10 单元和会话的每种题都生成一遍，查答案不在选项里、选项重复、听不出来的干扰项等
```

推送到 `main` 后，GitHub Actions 会自动部署到 GitHub Pages。
