# 普贤上师言教 藏文学习

以《大圆满前行·普贤上师言教》藏文原文为核心的藏文学习 PWA：从零基础拼读开始，逐步过渡到原文诵读和理解。读音为安多音。

## 内容来源

- 藏文原文：华智仁波切《普贤上师言教》。
- 读音：
  - 字母、元音组合（L-、CV-）和能对上的音节卡、词卡（`public/audio/real/`）用的是《安多方言会话教材》Flash 课件里的真人录音，由 `scripts/build_real_audio.py` 生成，每段的出处见 `scripts/data/amdo-real.tsv`，藏文 → 音频编号见 `src/real-audio.json`。
  - 文章部分（开篇整句、开篇逐词、全书原文）和教材里没有录音的音节、词，仍是 Meta MMS 安多藏语 TTS（`facebook/mms-tts-adx`，CC BY-NC 4.0）自动生成，尚未经人工校对。
- 中文译文有版权，**不在本仓库中**。需要时在 App 的“我的”页里导入本地的译文包。

## 课程结构

- **今日练习**（打开 App 停在路径页，没做完时弹窗提醒，点“开始”进入；路径页顶上也能进。`src/practice.ts`、`src/Practice.tsx`）：字卡 → 到期的单元抽查（最多 2 次）→ 到期复习（最多 15 题）→ 拼读线下一关 → 诵读开篇下一关 → 安多会话下一关。一步做完自动进下一步，中途退出回到清单接着做；当天的步骤在第一次打开时排好。**字卡做完就算签到。**一天大约 65 题（`DAILY_BUDGET`）：字卡、抽查、到期复习照做，剩下的额度按拼读、诵读开篇、安多会话的顺序排，复习多的日子先省掉后两样，做完后可以点“再学一点”加回来。没过的关在清单上标“这关没过，明天接着练”。每日字卡共 154 张（30 个字母、4 个单独的元音、120 个字母元音组合），循序渐进：先只考字母和元音，一个字母和 4 个元音都有点熟了（答过两次以上、最近没答错）才开始考这个字母的组合；字母表页还没开始考的组合行是灰的。每天 15 题：先放到期的，再补新卡（每天至少 5 张新卡；做字卡不到 7 天时最多 8 张），新卡 4 张一组，看完一组的介绍马上考这一组；干扰项只用已经见过的卡；按规律推出来的组合注音（灰色斜体）只考听音选字；第一次选错先给提示再选一次；进度只算本来的题，答错加的补练不算；组合卡显示拆开的读法（ཀ ga + ◌ི → ge），答错时也给你选的那个的拆法。做到一半退出，回来接着做。
- 第一次打开先看一屏欢迎页。底部 4 个页签：路径（今日练习入口 + 拼读路径）、原文、资料库（字母表 + 安多会话教材）、我的（复习记录 + 设置）。
- 路径上只显示拼读线；诵读开篇和安多会话不单独显示，每天在今日练习里学一点（会话新句子一关 3–4 句）。
- 每日小游戏暂时收起来了（`src/Games.tsx` 代码还在，没有入口）。

- **安多教材进路径**（《安多方言会话教材》，真人录音）：
  - 拼读线每个单元有一个“选学：口语词和拼读”关：教材 394 个词按“用到的字母、元音、加字都学过了”自动分到各单元，加上拼读表的真人录音（每单元最多 20 格），每次随机抽 10 个，可以反复做。选学关不挡后面的关，也不进单元小测、抽查和“已掌握”的判定。单元小测已经通过、后来才加进来的关算“补课”，同样不挡路。
  - 第三条线“安多会话”：300 句 15 句一个单元，共 21 个单元，从第一天就能学。每单元：听懂（四关，每关 3–4 句，听录音选意思）→ 认读（看藏文选意思、看中文选藏文）→ 说（排音节、听音选句）→ 小测。
  - 知识点：`A:编号`（会话）、`D:编号`（口语词）、`P:编号`（拼读表格子），都进遗忘曲线复习。
- **资料库页**：字母表，和教材全部内容，用来单独翻看和强化：会话 300 句、单词、拼读表、第 11–36 课课文（课本页面切成段，点哪段播哪段）。数据由 `scripts/build_amdo.py` 生成 `src/amdo.json`（含每个词的音节结构分析），录音和课文图片在 `public/amdo/`（约 47 MB，不预先缓存，用到才下载）。

- **拼读线**（单元 1–10，93 关）：字母、元音、加字，每关只学 2–3 个新东西，每三关有一关练习，单元最后是小测。字母按字母表顺序（ཀ ཁ ག ང …）带，和每日字卡一致；加字规则等用到的字母都学过再学。
- **诵读线**（单元 11 起，开篇原文）：一句一关。词卡用从整句连读里切出来的读音，最后听整句排词序、跟读。每天在今日练习里排一关。诵读关只考听音选词、看词选意思、看意思选词和排整句词序，不出转写题和听写拼音节（学的人可能还在拼读线前几个单元）。
- **回忆题**（`recallFor`，`src/course.ts`）：除了选择题，还有要自己想出来的题：拼字（听真人录音，给前加字、基字、元音……每个位置选字）、听写词（听一个词，从多给两块的音节里挑出来排好）、找错（音节拆解里有一处把别的字标成了基字，点出来）。新内容关的第二轮一半换成回忆题；复习、练一练、小测、抽查随机出题时三分之一是回忆题。听会话句选意思时选项晚 3 秒出（先想再看）。跟读后自评“读得像 / 还差一点”，差一点的早点再练。前加字、上加字、基字等在全 App 用固定颜色。
- **答题反馈**：第一次答错不直接给答案，而是按选了哪个错项给一句提示（形近字、音近字、元音、基字、词义、会话句，见 `src/hints.ts`），划掉这个选项再选一次；第二次还错才揭晓。作答记录里存了题型、用时、选错的选项和误区类别。
- **Wylie 转写**默认不显示，也不出转写题；“我的”页里可以打开（`src/prefs.ts`）。注音相同的清浊字，浊音那个的汉字后加“·浊”（如 ག ga 嘎·浊）。前加字、上加字、后加字的讲解按安多话：大多要读出来，以录音为准。
- **掌握判定**：一个知识点最近 7 次至少对 6 次，并且隔天还答对过。
- **FSRS 评分**：一次答对按用时分档（比这种题平时快很多 Easy、慢一倍以上 Hard、其余 Good），提示后才答对记 Hard，答错 Again；答对后可以点“其实是猜的”改记 Hard。
- **定时回顾**：字卡、路径、复习、抽查共用一份 FSRS 记录（`db.cards`），同一个字母只记一份熟练度。字母（`L:`）、元音（`V:`）和字母元音组合（`CV:`）到期后在每日字卡里复习，其余在到期复习里。旧版字卡的“盒子”记录在启动时由 `src/migrate.ts` 搬进 FSRS。到期复习按 FSRS 排；每个单元通过后第 1、3、7、14、30 天各有一次 10 题的抽查。

全书原文（开篇以外的 14 章，10,109 句）在“原文”页按章阅读：`scripts/build_book.py` 把句子表、botok 分词和整句音频的音节时间切成 `public/book/chNN.json`，整句音频转成 24 kbps 单声道 AAC 放在 `public/book/audio/`（约 170 MB）。这部分不预先缓存，打开哪一章才下载哪一章，听过的句子会存下来；每章也可以点“离线听本章”一次存完。点词时播的是整句音频里那个词的一段。全书中文译文同样不在仓库里，用“设置”导入全书译文包（含 `book` 字段，按段落编号 p0009… 存）。

**逐词释义和藏汉逐句对照**（`src/gloss.ts`、`src/align.ts`）：原文每个词下面有一行小字释义（“释义”按钮开关），点词看完整释义。词表 `scripts/data/book/gloss.tsv`（约 4400 条，按全书分词后的词形逐条写，高频词在前；释义前带 `?` 的是推测、还没核对，App 里标“推测”）由 `scripts/build_gloss.py` 生成 `public/book/gloss.json`，打开原文时才下载。查词顺序：课程词表里的人工释义 → 全书词表 → 去掉粘在词尾的助词（འི ས ར འང འམ འོ）再查，同时说明助词的作用 → 按音节拆成词表里有的几段分别给意思。整词能直接查到的约占全书词次 95.6%，拆开查到的约 4%。导入了全书译文后，“逐句对照”把每段译文按 ，。；：！？ 切成分句，再用动态规划按长度（汉字约为藏文音节的 1.3 倍）和词义（藏文词的释义在中文里出现）对到藏文句子上，几句藏文对一组中文，显示在这几句下面；点词时，这组中文里对应释义的字会标出来。译文语序和藏文不同，可能对偏一两句。`npm run check:align -- <全书译文包.json> [段落编号…]` 打印对照样例和命中率（译文包不在仓库里）。

每章读完最后有“做本章练习”（`src/bookQuiz.ts`，约 10 题）：本章出现的、词表或安多教材里有的词看词选意思；给一句原文选出句里的那个词；导入了译文的话，再给一段原文选中文意思。词题用原来的 `W:`/`D:` 知识点进复习，段落题记为 `B:段落编号`，只记作答，不进复习。

开篇逐词数据（分词、一本通式注音、音频编号）由 `scripts/build_opening_words.py` 从 `scripts/data/opening-words.tsv` 生成 `src/opening-words.json`；音频在 `public/audio/op/`。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建到 dist/
npm run check:align -- <全书译文包.json>  # 看逐句对照和逐词释义的效果
npm run check:questions  # 题库检查：把 1–10 单元和会话的每种题都生成一遍，查答案不在选项里、选项重复、听不出来的干扰项等
```

推送到 `main` 后，GitHub Actions 会自动部署到 GitHub Pages。
