# 普贤上师言教 藏文学习

以《大圆满前行·普贤上师言教》藏文原文为核心的藏文学习 PWA：从零基础拼读开始，逐步过渡到原文诵读和理解。读音为安多音。

## 内容来源

- 藏文原文：华智仁波切《普贤上师言教》。
- 读音：
  - 字母、元音组合（L-、CV-）和能对上的音节卡、词卡（`public/audio/real/`）用的是《安多方言会话教材》Flash 课件里的真人录音，由 `scripts/build_real_audio.py` 生成，每段的出处见 `scripts/data/amdo-real.tsv`，藏文 → 音频编号见 `src/real-audio.json`。
  - 文章部分（开篇整句、开篇逐词、全书原文）和教材里没有录音的音节、词，仍是 Meta MMS 安多藏语 TTS（`facebook/mms-tts-adx`，CC BY-NC 4.0）自动生成，尚未经人工校对。
- 中文译文有版权，**不在本仓库中**。需要时在 App 的“设置”里导入本地的译文包。

## 课程结构

- **会话页**（安多会话）：《安多方言会话教材》里拆出来的全部内容，都是真人录音。会话 300 句按 15 句一组，可以连续播放，也可以“练这一组”（看藏文选意思、看中文选藏文、听音选句、排音节顺序）；课本单词按页，每次练 10 个；拼读表（辅音、元音、前加字、上加字、下加字、后加字、再后加字、叠加字）点格子听音、点 ▶ 听整行连读；第 11–36 课课文是课本页面切成的一段一段，点哪段播哪段。练过的句子和单词进复习队列（知识点 `A:编号`、`D:编号`）。数据由 `scripts/build_amdo.py` 生成 `src/amdo.json`，录音和课文图片在 `public/amdo/`（约 47 MB，不预先缓存，用到才下载）。

- **拼读线**（单元 1–10）：字母、元音、加字，每关只学 2–3 个新东西，每三关有一关练习，单元最后是小测。
- **诵读线**（单元 11 起，开篇原文）：一句一关。词卡用从整句连读里切出来的读音，最后听整句排词序、跟读。两条线各自解锁，可以同时学。
- **定时回顾**：到期复习按 FSRS 排；每个单元通过后第 1、3、7、14、30 天各有一次 10 题的抽查。

全书原文（开篇以外的 14 章，10,109 句）在“原文”页按章阅读：`scripts/build_book.py` 把句子表、botok 分词和整句音频的音节时间切成 `public/book/chNN.json`，整句音频转成 24 kbps 单声道 AAC 放在 `public/book/audio/`（约 170 MB）。这部分不预先缓存，打开哪一章才下载哪一章，听过的句子会存下来；每章也可以点“离线听本章”一次存完。点词时播的是整句音频里那个词的一段。全书中文译文同样不在仓库里，用“设置”导入全书译文包（含 `book` 字段，按段落编号 p0009… 存）。

开篇逐词数据（分词、一本通式注音、音频编号）由 `scripts/build_opening_words.py` 从 `scripts/data/opening-words.tsv` 生成 `src/opening-words.json`；音频在 `public/audio/op/`。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建到 dist/
```

推送到 `main` 后，GitHub Actions 会自动部署到 GitHub Pages。
